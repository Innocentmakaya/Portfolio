TBTrack

TB Medication Adherence Monitoring Dashboard

Full-Stack Clinical Web Application for Remote Patient Monitoring

Problem Statement

Tuberculosis (TB) treatment requires patients to take medication consistently for several months. Missing doses can reduce treatment effectiveness, increase the risk of drug resistance, and make it difficult for healthcare professionals to monitor patient progress. In the first iteration of the Smart Pillbox project, patient adherence data was stored in Google Sheets. While this was suitable for prototyping, it lacked scalability, security, and advanced patient management capabilities required for a real-world healthcare system.

To address these limitations, TBTrack was developed as the second iteration of the Smart Pillbox project. TBTrack replaces the Google Sheets backend with a secure PostgreSQL database and provides healthcare professionals with a dedicated web platform for monitoring patients, tracking medication adherence, and managing treatment plans.

What is TBTrack?

TBTrack is a clinical web dashboard designed for healthcare professionals to remotely monitor tuberculosis patients using data collected from the Smart Pillbox system.

The platform allows healthcare workers to:

  • ✓ Manage patient records
  • ✓ Prescribe medications
  • ✓ Create treatment schedules
  • ✓ Monitor medication adherence
  • ✓ Track reported side effects
  • ✓ Schedule appointments
  • ✓ View treatment progress in real time

By centralising patient information in a secure database, TBTrack helps healthcare professionals make informed decisions and quickly identify patients who may be missing doses or experiencing treatment difficulties.

How It Works

TBTrack acts as the software monitoring layer of the Smart Pillbox system.

1

Patient Registration

Healthcare professionals create and manage patient records within the system.

2

Treatment Planning

Medications, dosage schedules, and treatment plans are assigned to patients.

3

Adherence Monitoring

Medication intake data from the Smart Pillbox is stored and displayed through interactive dashboards and visual reports.

4

Clinical Decision Support

Healthcare professionals review adherence trends, side effects, and appointments to support patient treatment and improve outcomes.

Development Process

1. System Architecture Design

Designed the application using an N-Layered Architecture to separate the frontend, backend, and database layers for better maintainability and scalability.

2. Database Design

Replaced the original Google Sheets storage system with a fully normalised PostgreSQL database consisting of seven interconnected tables for patients, medications, schedules, adherence logs, side effects, appointments, and healthcare workers.

3. Backend API Development

Built a RESTful API using Node.js and Express to handle patient management, medication scheduling, adherence tracking, appointments, and side-effect reporting.

4. Authentication & Security

Implemented secure authentication using JWT tokens, bcrypt password hashing, email verification, and password reset functionality to ensure only authorised healthcare professionals can access patient data.

5. Frontend Development

Developed a responsive user interface using React, TypeScript, and Tailwind CSS, providing healthcare professionals with an intuitive dashboard for patient management and monitoring.

6. Data Visualisation

Created interactive charts and treatment progress visualisations to help healthcare workers quickly understand patient adherence trends.

7. Testing & Validation

Tested all major workflows including authentication, patient management, medication scheduling, adherence tracking, and appointment management to ensure reliable operation.
