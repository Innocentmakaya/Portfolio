Lumina

Interactive Autonomous Exploratory Data Analysis Platform

AI-Powered Data Analysis, Visualization, and Cleaning Without Writing Code

Problem Statement

Data analysts and business professionals often spend a significant amount of time performing exploratory data analysis (EDA) before they can begin extracting meaningful insights from a dataset. This process typically involves writing code to calculate statistics, identify data quality issues, create visualizations, and clean the data.

For users without programming experience, these tasks can be difficult and time-consuming. Existing tools often require technical expertise or fail to provide intelligent guidance when analyzing datasets.

Lumina was developed to simplify this process by providing an interactive platform where users can upload CSV or Excel datasets and instantly receive statistical analysis, AI-powered insights, visualizations, and data cleaning tools through a user-friendly web interface.

What is Lumina?

Lumina is a full-stack Exploratory Data Analysis (EDA) platform that helps users understand and prepare datasets without writing code.

Users simply upload a dataset, and the platform automatically generates:

  • ✓ Statistical summaries
  • ✓ Data quality reports
  • ✓ Interactive visualizations
  • ✓ AI-generated insights
  • ✓ Data cleaning recommendations

The platform also includes an interactive chat interface that allows users to ask questions about their data using natural language.

A key feature of Lumina is its privacy-first architecture.

The AI model never receives raw dataset records and only works with pre-computed statistical summaries, making the platform suitable for sensitive datasets such as healthcare and financial data.

How It Works

1

Upload Dataset

Users upload a CSV or Excel file through the web application.

2

Automatic Data Profiling

The platform analyzes the dataset and calculates key statistics including missing values, duplicate records, distributions, correlations, and other quality metrics.

3

AI-Powered Insights

Verified statistical summaries are provided to the AI model, which generates meaningful observations and recommendations about the dataset.

4

Visualization & Data Cleaning

Users can explore charts, identify data issues, clean the dataset, and download the processed data for further analysis.

Development Process

1. System Architecture Design

Designed the platform as a full-stack web application with a React frontend and a FastAPI backend, following SOLID principles and clean architecture practices.

2. Dataset Processing Engine

Built a statistical analysis engine using Pandas that automatically profiles datasets regardless of their structure or schema.

3. Statistical Analysis Module

Implemented automated calculations for missing values, duplicate rows, distributions, quartiles, correlations, and other important dataset characteristics.

4. AI Integration

Integrated the Gemini 2.5 Flash model to generate insights and answer user questions about the dataset.

5. Privacy-First AI Architecture

Designed the system so that only statistical summaries are sent to the language model, ensuring that sensitive raw data never leaves the application.

6. Data Visualization System

Developed automatic chart generation including histograms, scatter plots, categorical charts, and correlation heatmaps to help users understand their data visually.

7. Interactive Data Cleaning Workflow

Built tools allowing users to handle missing values, remove duplicate records, and detect or manage outliers using the Interquartile Range (IQR) method.

Future Improvements

While Lumina already provides automated exploratory data analysis, visualization, and data cleaning capabilities, several enhancements are planned for future versions:

1. Additional Data Source Integrations

Expand the platform beyond CSV and Excel files to support direct connections to databases such as PostgreSQL, MySQL, SQL Server, and cloud data warehouses, allowing users to analyze live data without exporting files.

2. Advanced Machine Learning Capabilities

Introduce automated machine learning (AutoML) features for predictive analytics, classification, regression, and anomaly detection directly within the platform.

3. Automated Report Generation

Generate professional PDF and presentation-ready reports summarizing dataset quality, key insights, visualizations, and recommendations.
